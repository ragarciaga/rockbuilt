Found before the suite existed (manual run of fix-s1 on v0.1.0): with gh unauthenticated, `fix`
skipped the planner and the verifier and verified its own change. The verifier would have caught
a regression the run itself reported (`.trim()` on a missing category). Fixed by degraded mode
(DESIGN.md section 17). Re-run: planner, implementer, verifier ran; the verifier kicked back once
and asked for the missing-category test; one commit on `rb/L1-...`. Cost USD 1.23, 5 minutes.

Also found: adopt let `rb init` install the template CLAUDE.md before approval, so `rb baseline`
ran placeholder commands (typecheck, lint, build) and recorded a false red baseline. Fixed in the
skill order and with a guard in `rb baseline`.

Also found: two replies addressed the user as "usted". Register rule added to every skill.
